가사 영상 만들기 — 사용법

올리는 법 (넷리파이)
  이 폴더 전체를 넷리파이의 Deploys 화면에 끌어다 놓으면 됩니다. 빌드 설정은 필요 없습니다.
  내 컴퓨터에서 index.html을 더블클릭해 여는 방식으로는 동작하지 않습니다(글꼴과 프리셋 목록을 읽지 못함). 반드시 올려서 주소로 여세요.
  컴퓨터의 크롬 또는 엣지에서 사용하세요.

쓰는 순서
  1. 시점 기록: 음원과 가사를 넣고, 들으면서 Space로 줄마다 시작을 찍습니다. 간주에서는 X로 가사를 지웁니다.
  2. 세부 수정: 시점과 문구를 다듬고 SRT로 내려받거나 불러옵니다.
  3. 꾸미기와 배치: 배경 이미지와 이퀄라이저를 넣고, 글꼴·색·효과·위치·크기를 정합니다.
     배경·비율 탭에서 화면 비율(3:2, 16:9, 2:1, 1:1, 2:3, 9:16, 1:2)을 고르고, 배경을 끌거나 크기를 바꿔 보일 부분을 정합니다.
     배경은 화면보다 작게도 크게도 할 수 있고, 끌면 가운데와 화면 끝에 달라붙습니다. 화살표 단추나 키보드 화살표로 1픽셀씩 옮깁니다.
  4. 영상 뽑기: 짧은 변 1440, 30fps MOV로 저장됩니다. 소리는 원본 WAV 그대로 담깁니다.
     구간 자르기: 시작 줄과 끝 줄을 골라 대강 잡고 초 단위로 다듬습니다. 자른 영상 기준 SRT도 받을 수 있습니다.
     파일 형식: MOV(소리 원본 그대로, 기본값) 또는 MP4(어디서나 재생, 소리는 AAC 고음질 압축)를 고릅니다.
     화면전환: 시작과 끝에 검은 화면, 흰 화면, 흐림, 확대, 닦아내기, 원형 열림 중에서 고릅니다.
     소리 전환을 켜면 전환 구간의 소리만 서서히 조절되고 나머지는 원본 그대로입니다.
  작업 저장: 화면 위의 "작업 저장"으로 가사, 시점, 꾸밈 전체를 파일 하나로 저장하고 "작업 불러오기"로 다시 엽니다.
     음원, 배경 이미지, 곡 전용 이퀄라이저 파일은 저장되지 않으니 다시 넣어야 합니다.
  내 스타일: "내 스타일로 저장"을 누르면 지금의 글꼴, 색, 효과, 위치, 크기, 비율, 전환, 파일 형식이 이 브라우저에 기억되어 다음에 열 때 자동으로 적용됩니다.
     기기와 브라우저마다 따로 기억됩니다. 다른 기기로 옮기려면 작업 저장 파일을 쓰세요.

글꼴 추가 (코드 수정 없음)
  1. 글꼴 파일(woff2, ttf, otf)을 fonts 폴더에 넣습니다.
  2. fonts/list.txt 에 한 줄을 추가합니다.   파일이름 | 화면에 보일 이름
  3. 다시 올립니다.
  상업적 이용이 가능한 글꼴만 넣으세요. 기본으로 든 8종은 모두 SIL OFL 라이선스입니다(fonts/licenses).

이퀄라이저 프리셋 추가 (코드 수정 없음)
  1. 프리셋 파일(zip)을 eq 폴더에 넣습니다.
  2. eq/list.txt 에 한 줄을 추가합니다.   파일이름 | 화면에 보일 이름
  3. 다시 올립니다.
  프리셋은 글자 없는 흰색 모양이 한 마디(4박) 동안 움직이는 그림 묶음입니다. 색과 효과는 앱에서 입힙니다.

이퀄라이저 두 종류
  곡 전용 파일: 이퀄라이저 스킬이 만든 이름_web.zip. 제목과 박자가 이미 들어 있어 넣기만 하면 됩니다.
  프리셋: 어떤 곡에나 쓰는 모양. 3번 화면에서 박자를 눌러 빠르기를 맞추고, 제목은 제목 칸에 적습니다.

들어 있는 것

  lib/                    영상 파일을 묶는 라이브러리 mediabunny (MPL-2.0)
  fonts/                  글꼴과 목록
  eq/                     프리셋과 목록
